# Multithreaded Functional Kernel with O(1) Memory Allocator

A functional multithreaded kernel developed as part of the **Operating Systems 1 (OS1)** course at the University of Belgrade, School of Electrical Engineering (ETF).

## Overview

The project focuses on implementing core operating system concepts, including multithreading, thread management, synchronization, and efficient memory management.

The kernel provides a foundation for concurrent execution and resource management, featuring a custom memory allocator with **O(1) allocation and deallocation complexity**.

## Key Features

- **Multithreading** – Support for concurrent thread execution.
- **Thread Management** – Thread creation, scheduling, and lifecycle management.
- **Synchronization** – Mechanisms for coordinating concurrent threads and managing shared resources.
- **Context Switching** – Switching execution between threads.
- **Memory Management** – Custom memory allocation and deallocation.
- **O(1) Memory Allocator** – Constant-time memory allocation and deallocation operations.
